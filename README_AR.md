## بشكل سريع

يتيح لك **YT Radio Mode** لصق أي رابط لفيديو أو قائمة تشغيل من اليوتيوب، وإضافة فيديوهات إلى قائمة الانتظار، والاستمتاع بتشغيلها في الخلفية بسلاسة.

إذا تعذّر تشغيل فيديو معين (بسبب قيود العمر، أو الحظر الجغرافي، أو تعطيل التضمين من قِبل صاحب المقطع)، يقوم التطبيق تلقائيًا بإعادة محاولة تشغيل البث الصوتي عبر خوادم عامة لـ **Piped** أو **Invidious** بدلاً من تخطي المقطع.

## المميزات الرئيسية

- **إنشاء قائمة تشغيل من الروابط:** إمكانية لصق أي رابط فيديو أو قائمة تشغيل يوتيوب في مربع البحث.
- **خوادم بديلة طارئة:** التحويل التلقائي إلى البث الصوتي عبر خوادم Piped أو Invidious العامة في حال حظر يوتيوب للتضمين.
- **استئناف التشغيل:** متابعة الاستماع من حيث توقفت تمامًا عند إعادة فتح التطبيق.
- **12 ثيمًا مدمجًا:** التنقل بين الثيمات الداكنة والفاتحة ومجموعات ألوان مثل: Dark, Light, One Dark Pro, Catppuccin, Tokyo Night, Dracula, Material, Night Owl, Gruvbox, Rosé Pine, Kanagawa, و Poimandres.
- **واجهة ثنائية اللغة:** دعم كامل للغتين العربية والإنجليزية.
- **متوافق مع مختلف الأجهزة:** مصمم أولاً لأجهزة الكمبيوتر، ومع ذلك فهو متوافق تمامًا مع الهواتف والشاشات الذكية.

## اختصارات لوحة المفاتيح

اضغط على <kbd>?</kbd> في أي مكان داخل التطبيق لإظهار قائمة الاختصارات التفاعلية.

| المفتاح / الإختصار | الإجراء |
| :--- | :--- |
| <kbd>Space</kbd> / <kbd>K</kbd> | تشغيل / إيقاف مؤقت |
| <kbd>M</kbd> | كتم / إلغاء كتم الصوت |
| <kbd>A</kbd> | تفعيل / تعطيل التشغيل التلقائي |
| <kbd>Shift</kbd> + <kbd>N</kbd> | المقطع التالي |
| <kbd>Shift</kbd> + <kbd>P</kbd> | المقطع السابق |
| <kbd>Shift</kbd> + <kbd>L</kbd> | تفعيل / تعطيل وضع التكرار |
| <kbd>←</kbd> / <kbd>→</kbd> | تقديم / إرجاع المقطع |
| <kbd>↑</kbd> / <kbd>↓</kbd> | رفع / خفض الصوت |
| <kbd>,</kbd> / <kbd>.</kbd> | إبطاء / تسريع سرعة التشغيل |

## كيف يعمل؟

```text
[ لصق الرابط ] ──► [ تجربة YouTube IFrame API ] ──► ( نجح؟ تشغيل صوت الفيديو )
                                │
                        ( التضمين محظور؟ )
                                │
                                ▼
                [ التجربة عبر APIs لـ Piped / Invidious ]
                                │
                                ▼
                 ( بث الصوت عبر HTML5 <audio> )
```
## قيود معروفة
- ضمان الخوادم العامة:
تُدار خوادم Piped وInvidious العامة من قبل متطوعين، وتتعرض باستمرار للتقييد أو الحظر بواسطة اليوتيوب؛ وقد تتطلب قائمة الخوادم المدمجة إلى تحديثات دورية. يعد استضافة خادمك الخاص مضمونا أكثر على المدى الطويل.

- المحتوى المقيّد جغرافيًا أو حسب العمر:
لا يمكن تشغيل بعض الفيديوهات بأي طريقة بسبب قيود الترخيص الخاصة بـاليوتيوب نفسها، بغض النظر عن هذا التطبيق.

- عدم استخدام مفتاح API رسمي:
يعتمد هذا التطبيق على مشغل التضمين العام لليوتيوب ومشاريع طرف ثالث بدلاً من واجهة YouTube Data API الرسمية، لذلك قد يتغير سلوك التطبيق إذا عدّل اليوتيوب مشغل التضمين أو قام بإجراءات تمنع التضمين.
